# 05_visualizations — figures, maps, diagrams, charts



## Subfolders
- `cross_sections/` — geological cross-sections (Person 2)
- `well_logs/` — log panels (Person 2)
- `maps/` — areal maps (Person 2)
- `system_diagrams/` — process flow diagrams (Person 3)
- `charts/` — LCoE, sensitivity, distributions (Person 3 + Lead)
- `report_figures/` — final polished versions with fig_NN_ prefix (Person 4 curates)

## Format guidance
- Vector formats (`.svg`, `.pdf`) for diagrams, charts, maps where possible
- PNG at 300 dpi for non-vector figures
- JPG only for photographs
