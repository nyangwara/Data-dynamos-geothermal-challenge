# 02_data_processed — cleaned, derived, gap-filled datasets
Every file is reproducible from raw + code.

## Subfolders
- `cleaned_csv/` — repaired versions of raw tabular files
- `petrophysics/` — per-well petrophysical summaries
- `reservoir_summary/` — one-page-per-well reservoir characterization
- `tvd_conversions/` — MD↔TVD lookup tables (deviation surveys)
- `monte_carlo/` — uncertainty quantification outputs
