# subsurface_assessment_v01.xlsx

The well-by-well ranking and recommended doublet analysis for Challenge 1.

## Sheets
1. **Exec Summary** — well ranking table + recommendation block. BLT-01 highlighted as primary.
2. **Well Properties** — full property comparison (ThermoGIS vs LAS-derived) for all 4 wells.
3. **USP-01 Prediction** — IDW interpolation showing how predicted properties for the new well were derived, plus thermal breakthrough calculation (plug-flow ~103 years; practical ~34 years after ÷3 heterogeneity derate, at 1.5 km spacing).
