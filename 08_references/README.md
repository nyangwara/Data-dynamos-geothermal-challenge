# 08_references — external knowledge

Papers, screenshots, methodology references, prior art.

## Subfolders
- `papers/` — academic papers and reports as PDF
- `thermogis_screenshots/` — captures from ThermoGIS portal (with metadata.txt for each)
- `methodology/` — standard methodology docs (Larionov, density-porosity, LCoE definitions)
- `competitor_solutions/` — public examples of similar NL geothermal projects

## ThermoGIS screenshots discipline

Every screenshot saved with a sibling `_metadata.txt` containing URL, date captured, layer name, why we needed it. The challenge brief requires this documentation.
